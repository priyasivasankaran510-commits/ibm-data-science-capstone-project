# IBM Data Science Capstone Project

## SpaceX Falcon 9 First Stage Landing Prediction

### Project Overview
This project analyzes SpaceX Falcon 9 launches and investigates whether the first stage of a Falcon 9 rocket will land successfully.

### Project Objectives
- Collect SpaceX launch data using an API.
- Extract launch information using web scraping.
- Clean and prepare the collected data.
- Perform exploratory data analysis using Python visualizations and SQL.
- Visualize launch locations using Folium.
- Build an interactive dashboard using Plotly Dash.
- Apply machine learning classification algorithms to predict landing outcomes.

### Technologies Used
- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- SQL
- Folium
- Plotly Dash
- Scikit-learn

### Project Files
This repository contains Jupyter notebooks, dashboard files, and data used in the capstone project.
